### 语音验收（S5）

1. **路由：** 不在频道时音频只去 AI；在频道时音频只去频道；`wake` 后一个回合去 AI，之后回到频道。
2. **屏蔽：** 同频道的非好友听不到；好友听得到；好友被解除后正在进行的转发立即中断。
3. **发言权：** 同一频道同时只有一个人的音频被转发；其他人收到 `busy` 提示；发言人断线立即释放。
4. **优先级：** 听者正在播 AI 语音时，好友发言打断 AI；同一设备同一时刻只有一种来源的音频。
5. **背压：** 一个听者慢速消费不影响其他听者，队列满时丢最旧帧。
6. **延迟：** 服务端内部延迟 p95 < 100ms，日志里有每个 `Burst` 的首帧进出时间戳。

## 并行路线

```
轨道 A（语音主线）   S2 → S5 → S10 → W5          ← 关键路径，对应"陌生人屏蔽、好友互相听见"
                     S3 ↗   S4 ↗
轨道 B（AI 与开箱）  S2 → S6 → S7 → S8
轨道 C（家长端）     S1 → S3 → S8 → S9 → W6
前端                 W1、W7 立即开始；W3 依赖 M1；W2 跟随 S5；W4 跟随 S7；W5 跟随 S4/S10
```

优先安排 S2（它是 voice 和其他模块的前置）与 S3、S4（voice 的输入）。
