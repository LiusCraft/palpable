# 首页标题字体

`palpable-display.ttf` 是 Noto Sans SC 900 的字形子集，由 Google Fonts CSS API 提供，用于首页品牌名与标题。本地提供字体以避免首屏依赖外部字体服务；增加标题文字时需要同步扩充字形子集。

- 字体来源：https://fonts.google.com/noto/specimen/Noto+Sans+SC
- 子集接口：`https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@900&display=swap&text=<URL 编码的标题文字>`
- 许可证：[SIL Open Font License 1.1](OFL.txt)
